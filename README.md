# gdg-website
This repository contains the source code for the **GDG (Google Developer Group) Website**.  
The website is built to showcase GDG events, community activities, announcements, and provide a platform for developers to connect and learn.

---

## 🚀 Features

- Community-focused landing page
- Events and meetups section
- About GDG & mission
- Responsive design (mobile-friendly)
- Fast and modern UI
- Easy to maintain and extend

---

## 🛠️ Tech Stack

- **Frontend:** React / Next.js  
- **Styling:** CSS / Tailwind CSS  
- **Package Manager:** npm  
- **Version Control:** Git & GitHub
